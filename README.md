# Facktory Café — Landing Page

A modern and responsive landing page for a fictional coffee shop, designed to showcase products, brand identity, and location through a clean and intuitive user interface.

## Preview

![Facktory Café Preview](./img/Facktory Café Preview.png)

## About the Project

Facktory Café is a front-end development project created to practice and demonstrate web development fundamentals through a real-world inspired business website.

The interface was designed with a focus on visual consistency, usability, responsive layouts, and clear content organization.

## Features

- Responsive layout for desktop and mobile devices
- Navigation with smooth scrolling
- Hero section with custom visual identity
- Product menu with descriptions and pricing
- Brand and about section
- Location section with embedded Google Maps
- Contact section with social media links
- Interactive hover effects and visual transitions

## Technologies

- **HTML5** — Semantic page structure
- **CSS3** — Styling, Grid, Flexbox, transitions, and responsive design
- **Google Fonts** — Typography
- **Font Awesome** — Social media icons
- **Google Maps Embed** — Location integration

## Getting Started

1. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/facktory-cafe-landing-page.git
   ```

2. Open the project folder.
3. Open `index.html` in your browser.

No additional dependencies or build tools are required.
